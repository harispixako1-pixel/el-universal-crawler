# El Universal Crawler - Project Documentation

## Project Overview

**El Universal Crawler** is a Laravel-based web scraping application that automatically crawls, parses, and archives articles from El Universal (eluniversal.com.mx), a major Mexican news outlet.

## Purpose

- Discover and fetch articles from El Universal across multiple news sections
- Parse structured article data (title, author, content, publication date, category)
- Sanitize content by removing ads, promotional content, and junk text (Spanish language-specific rules)
- Store cleaned articles in the database for further processing or distribution
- Run crawls automatically on a daily schedule or manually via CLI

## Architecture

The crawler follows a pipeline architecture with separated concerns:

### Core Components (`app/Services/Crawler/`)

- **ElUniversalCrawler** - Main orchestrator; coordinates the entire crawling pipeline
- **UrlDiscoverer** - Discovers article URLs from El Universal homepage and sections
- **ArticleFetcher** - Fetches HTML content from discovered article URLs
- **ArticleParser** - Extracts structured data (title, author, content, metadata) from HTML
- **ArticleNormalizer** - Cleans and normalizes extracted article data for consistency
- **ContentSanitizer** - Removes junk content using configurable language-specific rules

### Data Models (`app/Models/`)

- **Article** - Stores crawled articles with fields: title, url, published_at, author, content, category, source

### Console Commands (`app/Console/Commands/`)

- **CrawlElUniversal** - CLI command to manually trigger crawls with configurable limits

## Tech Stack

- **Framework**: Laravel 13.17
- **PHP**: 8.3+
- **Database**: Configurable (Laravel supports MySQL, PostgreSQL, SQLite)
- **HTML Parsing**: Symfony DomCrawler & CSS Selector
- **HTTP Client**: Laravel HTTP Facade
- **Testing**: PestPHP
- **Linting**: Laravel Pint

## Key Configuration Files

- `config/sanitizer.php` - Content sanitization rules (Spanish language junk phrases, ads, etc.)
- `config/app.php` - Application settings
- `config/database.php` - Database connection settings

## Running the Crawler

### Manual Execution

```bash
# Crawl with default limit (10 articles)
php artisan crawler:run

# Crawl with custom limit (5 articles)
php artisan crawler:run --limit=5
```
